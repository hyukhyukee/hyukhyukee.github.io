# Jang Jae-hyuk Portfolio

[한국어](#한국어) · [English](#english)

## 한국어

생성형 AI 기반 디지털 콘텐츠 제작 및 AI 이미지 워크플로우 구축 경험을 정리한 개인 포트폴리오입니다.

Stable Diffusion, ComfyUI 등 로컬 AI 환경을 활용한 이미지 생성, 프롬프트 엔지니어링, 모델 테스트 및 글로벌 콘텐츠 플랫폼 운영 경험을 포함합니다.

## 프로젝트 목적

생성형 AI 기술이 빠르게 발전하면서 다양한 모델과 도구가 등장하고 있습니다.

이에 따라 단순 이미지 생성에 그치지 않고,
Stable Diffusion 기반 로컬 환경을 직접 구축하여
Checkpoint, LoRA, VAE, Prompt 조합에 따른 결과 변화를 분석하고
효율적인 AI 이미지 생성 Workflow를 연구했습니다.

또한 반복적인 생성 작업을 효율화하기 위해
Batch 생성, 모델 관리, 이미지 관리 환경을 구성하며
실제 콘텐츠 제작 과정에 적용했습니다.

## English

Personal portfolio showcasing experience in generative AI content creation, AI image workflow development, and digital content production.

This portfolio includes experience in building local AI environments using Stable Diffusion and ComfyUI, prompt engineering, model testing, workflow optimization, and global creator platform management.

## Project Purpose

With the rapid development of generative AI technology, various models and tools are continuously emerging.

Rather than focusing only on image generation, this project aims to build and optimize a local Stable Diffusion-based environment while analyzing the effects of Checkpoints, LoRAs, VAEs, and prompt combinations.

The workflow was also improved through batch generation, model management, and asset organization methods to apply generative AI technology to practical content production.

## Featured Projects

- **AI Digital Content Creation & Global Platform Operation**
  - Created and published generative AI-based illustrations regularly
  - Managed content distribution and communication with a global audience
  - Analyzed user responses and artwork data to improve content direction

- **Local AI Image Generation Pipeline**
  - Built Stable Diffusion WebUI Forge and ComfyUI-based generation environments
  - Tested Checkpoint, LoRA, and VAE combinations and analyzed output differences
  - Optimized local AI workflows using an RTX 5060 Ti GPU environment

- **AI Content Workflow Optimization**
  - Developed batch generation and asset management workflows for efficient production
  - Tested new image generation models and related AI technologies
  - Improved output quality through prompt refinement and workflow adjustments
